# Smart Assignment Maker Frontend

React + Vite frontend for Smart Assignment Maker.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Environment

Copy `.env.example` to `.env` and set:

```bash
VITE_API_URL=http://127.0.0.1:8000
```

For deployment, set `VITE_API_URL` to the live backend URL.
